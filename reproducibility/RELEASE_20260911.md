# Evidence provenance and verification

The repository contains the code and evidence for the current paper. The
[result-to-command map](PROVENANCE.md) and [reproduction guide](README.md)
are the entry points for reproducing its results.

The sequential-audit archive contains 39 payloads plus two manifests. Its exact
SHA256 is recorded in the sidecar and `release_20260911.json`. Run the audit
from its extracted directory so it uses its measured solver package, including
the helper modules imported by that package. See the
[verification commands](../journal_evidence/README.md).

`release_20260911.json` records the packaging provenance and checks performed
when these artifacts were collected. Source commit identifiers, configuration
versions and file hashes identify the inputs to reported experiments. They
allow a result to be traced to its execution code as the repository evolves.

Full experiment reruns require the inputs and hardware listed in the
reproduction guide. Saved aggregate checks do not reconstruct excluded
per-record clinical outputs. Timing measurements remain platform-dependent.
